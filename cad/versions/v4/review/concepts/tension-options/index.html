V4 · String adjustment without an inline rubber band

Official V4

Concepts only. Each proposed part is a flat extrusion with through-openings, designed to avoid supports; no slice or strength verification yet. The tool view uses a shortened shaft and schematic cord path, not a clearance audit.

No inline rubber band is assumed. A/B adjust cord length but provide no overtravel compliance. C explores a printed TPU flexure instead; its force, creep and travel are unknown. Keep the actuator return band to release the button. The 12.6 mm stop prevents plunger escape; it is not a safe button-force limit.
