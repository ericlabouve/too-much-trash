Scope and unresolved checks

Review only, not active V3 manufacturing files. C: fixed cuff 21.6 mm, sliding cuffs 21.6 mm at ±50 mm. A/B: earlier 40 mm fixed cuffs. The fixed C cuff has NO attachment yet. New widths and retainers are unprinted.

TPU 95A is intended for the cuff; PETG can test fit but cannot establish soft grip. A transverse key can block the larger T pulling out, but the transverse key itself can still drift. TPU creep, peel, strength, actual camera field of view, phone seating, actuator/service travel and slicing need further work. This concept does not fix existing twine-routing issues.

Original 18/20 mm phone examples remain too thick for the unchanged C profile. C uses the actual 8 mm example at Z10..18; undeformed TPU seating overlap is reported, not hidden. No universal fit or button-clearance claim.
