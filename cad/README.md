# CAD studio

The [reference photo](reference/reacher-grabber.png) shows the exact reacher-grabber model for this retrofit. Source models in [source](source/README.md), printer-ready files in [print](print/README.md), and technical concept drawings in [renders](renders/README.md) belong here. The neck-mounted iPhone, external cable route, handle trigger coupling, and button actuator are separate parts to measure and prototype.

The drawings are visual concepts, not dimensioned manufacturing drawings. Fit, force, cable travel, phone-button alignment, camera sight line, and safe claw clearance need physical validation before printing a final design.
