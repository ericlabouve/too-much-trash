Experiment loop

      

        

          Pin data and split
          
Select datasets and freeze the seeded random train, validation and test partition for this run.

        

        

          Research fresh candidates
          
Researchers propose the configured number of fresh ideas. New Family requests one new architecture and an independent review.

        

        

          Evolve and train children
          
Dispatch a task per selected parent, compare previous failures, implement children and fit learned models on training clips only.

        

        

          Measure candidate performance
          
Measure event F1 and runtime under the pinned protocol. Run latency measurements sequentially after fitting stops; keep test clips reserved.

        

        

          Review streaming integrity
          
Independent final reviewers inspect frozen code and weights, challenge timing shortcuts, future access and clip resets, and test continuous-state behavior. Unapproved candidates cannot enter the pool.

        

        

          Audit the evidence
          
Verify reviewer approvals and artifact hashes, actual subagent receipts, training provenance, saved predictions, timings and fitness before publishing the selected pool.

        

        

          Save and repeat
          
Save the scored pool, lineage and run artifacts. Start the next round when ready. Research and evolution repeat each round.

        

      

      
Final test evaluation and iPhone benchmarking are separate milestones after candidate selection. The test split stays reserved during evolution.
