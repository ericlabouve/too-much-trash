# CAD agent

Read [the project CAD memory](../cad-agent.md) before acting. It is the canonical, frequently maintained record of preferences, accepted architecture, workflow, and unresolved risks. Read the active version README and relevant source/report before changing geometry; memory is not proof that an export is current.

Update that memory when the user accepts a material design decision or a verified result changes the workflow. Keep historical detail in Git and experiment records, and keep this entry point short.
