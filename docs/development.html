PROJECT GUIDE / FIRST DRAFT

Development

Too Much Trash spans field capture, a hosted service, review tools, research workflows, and a physical reacher retrofit. Start with the area you want to work on.

Current status

This repository is an early scaffold and CAD fit prototype. Capture, authentication, media upload, processing flows, and model training are planned. The printable design has not been physically validated.

LOCAL PREVIEW

Run the existing stack

Copy .env.example to .env, replace the example passwords, and run the Compose stack from the repository root. Caddy serves the public site at /, the browser workspace at /app/, and proxies /api/* to FastAPI. The health endpoint is /api/v1/health.

cp .env.example .env
# Edit .env before starting the stack
docker compose up --build

For a desktop preview, run npm install and npm run desktop in frontend/ while the stack is running. The iOS project is described by ios/project.yml for XcodeGen.

For full component details, use the development note and the README in each component directory.
